# Auto Tab Focus - Brave Browser

Automatically focuses new tabs opened with middle click or Ctrl+Click.
It's open source and easy to download and setup!

## Installation
1.Go to brave://extensions and enable "Developer Mode" on the top right.
You will see an option "Load UnPacked", click on it.

2.Download the extension.
Extract the extension ( It's not important where).

3.Then go back to your Brave Browser and select the folder of the extracted extension.

4.Click OK and enjoy :)
